# v0.9 Admin Operations Guide

## Member approval

1. Open **Members**.
2. Filter by `SUBMITTED` or `UNDER_REVIEW`.
3. Open the member record.
4. Review each uploaded document.
5. Approve or reject documents as needed.
6. Approve the member once the application and document checks are complete.

## Event attendance

Use **Event Registration** and the Attendance Desk. Enter the attendee ticket code and select **Check in**. The response displays the attendee and current attendance status.

## Publishing

Use **Publishing workflow** for controlled content release. The scheduler accepts a future date/time. The background worker is responsible for applying scheduled publication.

## Reporting

Use **Reports** for non-financial operational reporting. Finance transactions remain behind the finance permission and are available from the Payment module.
